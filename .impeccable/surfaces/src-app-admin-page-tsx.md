# Administration

Mode: Operate. A dedicated administrator needs to understand customer use and service problems within one scan, on desktop or phone.

Established world: inherit DESIGN.md's neutral surfaces, Assistant labels, Inter tabular figures, restrained accents, flat rows, and logical RTL spacing. The user's pinned request is a simple, useful dashboard without surplus text, headings, or buttons. Shape this surface directly within that world.

Implemented direction: one compact header; four statistical values in one desktop strip and a 2 × 2 phone grid; a fourteen-day created/completed chart beside service status; a searchable user table with 25 rows per page; password change closed behind a disclosure. No sidebar or personal task tools on administrator accounts. The 1120px main container uses neutral ground, hairline divisions and flat rows. Below 960px, chart and services stack; below 600px, search fills its row and activity moves beneath each user's identity. Long names and emails wrap at 320px.

Interaction contract: each day's paired bars exposes its date and actual counts on hover or keyboard focus, with an accessible count label. Created uses `--muted`; completed uses `--swatch-teal`, with written series labels. The first and last four days anchor their tooltip inward. Refresh conveys loading, respects reduced motion and refreshes visible idle views every minute. Search waits 350ms, retains the query in the URL, resets pagination and has a clear path when empty. Password fields, pending, errors and success appear only after opening the disclosure; there is no entrance choreography.

Header accessibility: controls retain accessible labels at mobile widths. Logout explicitly keeps `aria-label="יציאה"` and `title="יציאה"` when its visible text is hidden, including at 320px; the browser scenario logs out after resizing to that width.

Data truth: only `role = user` accounts contribute to customer totals and user rows. Activity is the most recent authenticated request, throttled to ten minutes; historical activity is backfilled only from existing session creation. Missing activity says `אין נתון`; one hour says `לפני שעה`. Seven-day figures are rolling seven-day windows. Daily charts use Asia/Jerusalem, including DST. WhatsApp has stale-heartbeat handling and actual outbound/failure counts; email and Google labels say configured, never delivery or uptime. User rows expose identity, counts, activity and connected services. Private task content, phone numbers, password hashes, provider credentials/tokens, and raw provider errors are excluded.

Permissions: every cross-account overview query verifies `role = admin` from the current database rather than trusting a submitted or cached role. Public registration ignores a submitted role. Dedicated administrator accounts land at /admin and are redirected there from /app. The existing named WhatsApp operator remains a service operator, without access to this dashboard. Account provisioning is a separate operator-only script; no public promotion endpoint exists.

Ship review: `.impeccable/review/admin-review.md` records `disposition: ship` for the local surface. Desktop 1440, phone 390, narrow phone 320 and desktop dark captures were inspected; empty search and real Tab focus for days 0, 1, 12 and 13 were reviewed. The four default views have no recorded page overflow, undersized checked controls, private text leakage or browser exceptions. Evidence uses a separate local database with synthetic users under `.impeccable/review/`.

Supporting implementation handoff: 352 unit tests (including the added operator-role case), 98 browser scenarios, meaningful local search/password/pagination flows, ordinary-account and forged-session denial, and tooltip bounds passed. These results are reported execution evidence, not tests rerun by the documenter or reviewer. Production deployment and administrator creation require separate live checks; the local ship verdict does not certify release, live service health or message delivery.

Password reset extension: beneath each customer's identity, a compact underlined `איפוס סיסמה` button has a 44px target and an accessible name containing the stored recipient email. Pending and cooldown disable it; sent, error and truthful local preview feedback wraps within the row. The server verifies the current administrator before any target/email lookup, accepts only role=user recipients and their stored email, and exposes no token or password choice to the administrator. Existing one-hour, single-use recovery changes password and sessions only when the recipient completes it; concurrent issuance enforces a 60-second resend minimum and at most three live tokens. Recovery URLs are excluded from visitor analytics. `.impeccable/review/admin-reset-review.md` records the addition's local ship verdict, desktop/mobile/narrow/dark/feedback captures and 44px, overflow and privacy checks; reported execution is nine new backend tests, six existing mail tests and ten targeted browser scenarios. Deployment and live email delivery require separate evidence.
